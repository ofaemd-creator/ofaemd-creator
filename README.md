## 👨‍⚕️ About Me & Research Mission

I am **Dr. Ömer Faruk Aydın**, a physician and systems computer scientist working at the convergence of **clinical medicine**, **formal verification**, and **autonomous multi-agent operating systems**. 

My work addresses three foundational challenges in modern computational systems:
1. **Biomedical Sensor Reliability:** Engineering autonomic calibration algorithms grounded in contractive Lyapunov stability ($V_{k+1} < V_k$) that eliminate baseline drift in intensive care hemodynamic and electrocardiographic telemetry without manual recalibration.
2. **Formal Numerical Safety:** Developing the **SYNAX (`.sx`)** programming language and interval abstract interpretation compiler capable of mathematically certifying 0-ULP IEEE-754 arithmetic safety across ARM64 NEON, x86_64 AVX2, and fixed-point microcontrollers.
3. **Sovereign Multi-Agent Architecture:** Designing **SYNAX-OS**, a microkernel-based agentic operating system that replaces brittle single-turn prompts with preemptive priority scheduling, inter-process communication (IPC), AST-audited sandboxing, and verifiable multi-agent pipelines.

## 🔬 Core Scientific & Technical Pillars

### 1. Contractive Lyapunov Stability for Sensor Auto-Calibration
In hemodynamic and critical care monitoring, sensor baseline drift $\Delta(t)$ degrades diagnostic precision over time. SYNAX incorporates an autonomic discrete-time error contraction law:
$$e_{k+1} = (1 - \gamma) e_k, \quad 0 < \gamma < 1$$
Adopting the quadratic Lyapunov candidate energy $V_k = e_k^2$, the system guarantees:
$$V_{k+1} = (1 - \gamma)^2 V_k < V_k \quad \forall e_k \neq 0$$
This provides asymptotic convergence of baseline drift to zero without manual zeroing procedures.

### 2. DerSimonian-Laird Random-Effects Meta-Analysis & PRISMA 2020
SYNAX integrates verified biomedical evidence aggregation:
- Dynamic PRISMA flow accounting tracking identification, screening, and quantitative eligibility.
- DerSimonian-Laird variance component estimator $\tau^2$:
  $$\tau^2 = \max\left(0, \frac{Q - (k-1)}{S_1 - \frac{S_2}{S_1}}\right)$$
- Strict scientific honesty: returns `INSUFFICIENT_VERIFIED_DATA` when empirical parameters are absent, completely prohibiting synthetic data fabrication.

### 3. AST-Audited Microkernel & Secure Sandbox
AI-generated code execution is insulated through an in-depth security architecture:
- Static abstract syntax tree auditing rejecting dangerous built-ins and OS access.
- Disposable temporary workspaces with strict CPU timeouts (`RLIMIT_CPU`) and memory ceilings (`RLIMIT_AS`).
- Human-in-the-loop authorization gates for critical operations.
